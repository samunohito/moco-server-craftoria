# Craftoria ProbeJS typing snapshot

Target baseline: Craftoria 1.36.0, Minecraft 1.21.1, NeoForge 21.1.249,
and KubeJS 2101.7.2-build.377.

The checked-in declarations have not yet been regenerated for this baseline.
Do not treat them as authoritative until ProbeJS 8 has completed a fresh in-game
dump and `pnpm run capture-typings` has refreshed this snapshot.

Only the generated TypeScript declarations are distributed. ProbeJS caches,
source JARs, workspace snippets, and runtime logs are intentionally excluded.

The declarations were relocated from ProbeJS 8's `.probe/` directory to
`kubejs/probe/`; the adjacent script-side `jsconfig.json` files contain the
corresponding relative path mappings.
